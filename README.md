# README

## 🚀 Getting Started

**Prerequisites:**

Make sure you have the following installed:

> Ruby version - 3.4 or higher <br/>
> Ruby on Rails (8.x.x) <br/>
> Bundler <br/>
> Database (e.g. PostgreSQL / MySQL )

----------

**1. Clone the Repository**
```sh
git clone https://github.com/vikash-k-singh/kiosk_api.git
cd <your-repo>
```


Or if you have a repo in zip

**Unzip the file on local.**
```sh
cd <your-unzipped-repo>
```

----------

**2. Install Dependencies**
```sh
bundle install
```

----------

**3. Setup Database**
```sh
rails db:create
rails db:migrate
```

----------

**5. Start the Server**
```sh
rails server
```

Visit: http://localhost:3000

----------

**6. Run Tests**
```sh
rspec .             # rspec test case execution
```

----------

**7. Common Commands**
```sh
rails console        # open Rails console
rails routes         # list routes
rails db:reset       # reset database
```
